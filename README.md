# GitBucket

## Overview
- GitBucket build for TerraMaster OS
- Official: https://gitbucket.org/

## Installation
1. Requirements: TOS 7.0+
2. Install from TOS App Center or manually


## Usage
How to access and use the app:

1. Access URL: `http://<yourdomain>:8086`
2. Access URL: `https://<yourdomain>:18086`

## Permissions
| User: GitBucket | Isolated service execution |


## Ports
| Port | Protocol | Purpose |
|---|---|---|
| 8086 | TCP or both | WebUI http |
| 18086 | TCP or both | WebUI https |
